# 口播分镜

把一篇口播稿变成：一张给人改的分镜表，再加一组按所选模型时长切开、带参考绑定的视频提示词。

本 skill 服务口播工作台，不是短剧分镜。不要从稿子里新造人物、场景或音色；只用用户已选定的资产。

## 输入

必填：

- 口播稿
- 人物（名称 + 人物多视图）
- 场景（名称 + 场景多视图）
- 音色（名称 + ≤15 秒参考音频）
- 视频模型

选填：

- 画幅（默认 `16:9`，可选 `9:16`）
- 分辨率（默认 `720p`，可选 `480p` / `720p`）
- 姿态（不填则按场景推断）
- 输出只要分镜表、只要视频组、或只要 JSON

模型单段时限：

| 模型 | 最短 | 最长 |
|---|---:|---:|
| seedance-2.0 | 4s | 15s |
| seedance-2.0-fast | 4s | 15s |
| seedance-2.0-mini | 4s | 15s |
| seedance-2.5 | 4s | 30s |
| seedance-2.0-real | 4s | 15s |
| seedance-2.0-fast-real | 4s | 15s |
| seedance-2.0-mini-real | 4s | 15s |
| seedance-2.5-real | 4s | 30s |
| 其他全能参考模型 | 4s | 以该模型单段上限为准；未知则 15s |

## 和短剧分镜的区别

不要套用短剧习惯：

- 不抽取角色/场景/道具清单，资产已选定。
- 不加戏、不空镜、不切听众反应、不切产品特写。
- 不写多角色左右站位。
- 不把稿子改成对白戏；默认一人对镜头说话。
- 运镜默认克制。口播 skill 禁止走动、换景、绕拍、甩镜。
- 音色是参考音频，不是成片音轨。模型必须按该音色 **逐字** 说本段台词，不得改写、概括、加口头禅。
- 第 1 段不合成「人在场景中」的首帧图；人物板 + 场景板作为参考图直接绑定。
- 第 2 段起必须吃上一段尾帧。

## 姿态与机位

姿态只允许 `坐` 或 `站`，全程不变。

未指定时：

- 演播室、会议室、访谈桌、播音台 → `坐`
- 演讲台、教室讲台、发布会台 → `站`
- 仍不确定 → `站`，面向镜头，停在场景主机位

默认画面：

- 景别：中近景胸像；个别强调句可用近景，不要频繁切换
- 朝向：面部和身体正对镜头，或最多偏 15°；可略向镜头前倾，增强亲和力
- 运镜：`固定`；一段里最多一次极轻 `Dolly In`
- 表情：自然微笑、有神采、亲和有感染力；随台词内容有自然的情绪起伏（点头、挑眉、眨眼、会心一笑），不要全程板着一张脸
- 动作：眨眼、呼吸、轻微点头；手势可有活力，但保持在画面内、胸口至肩部附近，如指点、张开、轻握，避免手挡脸或出画
- 场景：只用所选场景多视图里的主机位空间，不换房间

禁止：

- 起身、坐下切换、走动、出画、明显转身
- 换装、换发型、换年龄、换脸
- 第二个人、观众、虚化路人
- 手挡脸、手玩麦、手离开画面后再凭空长回来
- 画面内任何叠加文字：字幕、花字、角标、水印、Logo、标题卡、进度条、时间戳、平台标识、提示条
- 背景音乐、配乐、歌曲
- 无故切空镜、物品特写、闪回

## 切段

1. 按口播稿顺序切，不打乱、不删句、不补句。台词必须原文进入分镜和视频组，字不能改。
2. 必须先理解内容的语义结构，再决定切点。用户输入的标点可能有误：句号可能只是逗号级停顿，逗号也可能是语义段落的结束。标点只是参考，不是切段指令。
3. 只在内容上可以明显停顿的位置切段：前一段已完成一个观点、事实、步骤或转折，后一段可以自然起句。不得拆开主谓宾、因果、条件与结果、转折前后或同一个完整论点。
4. 一组 = 一次视频生成。在容量允许时必须优先保留完整语义并使用最少视频组，尽量让每段接近模型最长时长。
5. 时长估算有 1s 容差。若一个完整语义段的估算时长仅超出模型上限 1s 以内，例如估算 16s 而模型上限为 15s，仍放在同一视频组，并将 `duration_sec` 设为 15s；不要为这 1s 估算偏差拆成两段。
6. 若估算时长超出模型上限 1s 以上，才在最佳语义停顿处切分；不要为了精确装满时长而破坏语义。
7. 单段不要短于模型最短时长。末段过短时，优先调整上一个语义切点，不要留下零碎尾句。
8. `duration_sec` 不得超过模型的硬性最长时长。每段内部时间码从 `[0s]` 起算，最后一拍的终点 = 本段时长。

时长估算（切段用，不是成片字幕轴）：

- 正常口播：约 5.5 字/秒
- 快、激动：约 6.5 字/秒
- 慢、郑重、轻声：约 4 字/秒
- 每段开头加约 0.3s 起势；内容上需要明显停顿的地方每处加约 0.15s 气口，不要机械按用户标点计数
- 稿子未标明情绪时按正常口播（5.5 字/秒）估

## 分镜表

给人在界面里改。改的是这些列，不是散文。

| 序号 | 台词 | 时长 | 景别 | 运镜 | 姿态 | 朝向 | 动作 | 情绪 | 画面 | 承接 | 尾帧 |
|---|---|---|---|---|---|---|---|---|---|---|---|

列规则：

- `台词`：本段要说的原文。
- `时长`：秒，一位小数亦可，必须落在当前模型时限内。
- `景别`：`中近景` / `近景` / `中景`。默认 `中近景`。
- `运镜`：`固定` 或 `固定，后段极轻 Dolly In`。
- `姿态`：`坐` 或 `站`，与全片一致。
- `朝向`：如 `面向镜头`、`面略偏左 10°`。
- `动作`：第 1 段以 `(开篇)` 起；之后以 `(承接上段尾帧)` 起，再写本段可见动作。
- `情绪`：说话状态与语气语调。默认 `活泼亲切、清晰有力、有感染力的教学口吻`：语速偏快、密集连贯、吐字清晰、抑扬顿挫。可按内容换 `热情`、`娓娓道来`、`沉稳` 等。不要写成小说心理活动。
- `画面`：人在场景里怎么站/坐、手和视线、和讲台/桌的关系。写得能拍，不要写抽象形容词堆砌。
- `承接`：第 1 段 `开篇`；之后 `承接上段尾帧`。
- `尾帧`：本段结束时的姿势、视线、手的位置、口型收住。工作台会抽取真正的最后一个有效视频帧，保存无损 PNG 后通过 FFmpeg 逐像素提取同尺寸结构线稿，供下一段约束构图和人物位置。

## 视频组

分镜表之后输出视频组。一组对应一次模型调用。

### 参考绑定

每组都要写清参考槽，便于工作台挂文件：

第 1 段：

- 图1 人物多视图：锁定身份、脸、发型、服装、体态
- 图2 场景多视图：锁定空间、主机位、灯光、家具陈设
- 音频1 音色参考：只用这段声音的音色和说话方式；内容以本段台词为准

第 2 段起，在上面三条之外增加：

- 图3 上一段精确尾帧逐像素提取的结构线稿：它与尾帧画幅和分辨率相同，只负责锁定机位、透视、构图、人物中心坐标、人物边界、头部大小、身体占画面比例和四周留白；它是普通参考图，不是本段首帧，人物与场景的写实外观分别以图1和图2为准
- 可选 视频1 上一段成片：只参考动作连续和空间，不参考其台词内容

人物板、场景板、音色每一段都要继续挂上，不能从第 2 段起只传尾帧参考图。

### 模板

```md
### 视频组1
模型: seedance-2.0
时长: 12s
画幅: 16:9
分辨率: 720p
姿态: 坐

参考绑定:
- 图1 人物多视图：锁定身份、脸、发型、服装、体态
- 图2 场景多视图：锁定空间、主机位、灯光、家具陈设
- 音频1 音色参考：用此音色逐字朗读本段台词，不改词、不唱歌、不配乐

场景: 演播室
角色: 李主播
承接: 开篇

运镜+画面：[0-8s]
画面：...
运镜：固定
声音：房间轻微底噪。台词（沉稳）：原文

[8-12s]
画面：...
运镜：极轻 Dolly In
声音：台词（续，沉稳）：原文

尾帧: 面向镜头，双手放松搭在桌沿，嘴自然闭合，准备接下句
其他需求：面部五官清晰稳定不变形；口型与本段台词同步；人物与图1一致；场景与图2一致；人体比例正常；动作连续不跳帧；不添加第二人；不换装不换发型；无模糊无重影；无字幕无花字无Logo；无背景音乐；必须逐字朗读本段台词，不改写不概括不增删。
```

第 2 段起把 `承接` 写成 `承接上段尾帧`，并补上图3结构线稿（及可选视频1）。明确图3是同尺寸坐标约束图和普通参考图，不是首帧；不得重新构图、改变人物比例或生成线稿转写实的过程。`其他需求` 固定用上面这句，除非用户改了技术约束。

### 提示词写法

- 每个时间片都必须有 `画面：`、`运镜：`、`声音：`。
- `画面` 写：景别、人在画面中的位置、坐/站、和桌/台的接触、手、视线、口型开合、表情。点明「与人物多视图同一人」「与场景多视图同一空间」。
- 第 2 段起第一拍先写严格按结构线稿的坐标关系自然承接：镜头机位、透视、景别、人物中心点、人物边界、头部大小、身体占画面比例和四周留白一一对应；不得重新构图、裁切、缩放、推拉或居中人物。
- 用能生成的词：`中近景`、`近景`、`固定`、`极轻 Dolly In`、`浅焦背景`、`演播室面光`。不要用 `Crash Zoom`、`Orbit`、`手持晃`、`甩镜`。
- `声音` 只写现场底噪和台词。台词格式：`台词（情绪）：原文`；跨拍续念用 `台词（续，情绪）：原文`。
- 不要在提示词里点名具体字幕内容、品牌 Logo、屏幕小字。
- 每组结尾用 `尾帧` 写死结束状态，供工作台抽取无损 PNG、逐像素提取同尺寸结构线稿并绑定到下一段。

## 工作台 JSON

工作台以 JSON 为源，分镜表和视频组由同一份数据渲染。字段不要另起一套名字。

```json
{
  "skill": "koubo",
  "model": "seedance-2.0",
  "aspect_ratio": "16:9",
  "resolution": "720p",
  "stance": "坐",
  "assets": {
    "character": "李主播",
    "scene": "演播室",
    "voice": "李主播默认音色"
  },
  "shots": [
    {
      "index": 1,
      "dialogue": "原文台词",
      "duration_sec": 12,
      "shot_size": "中近景",
      "camera": "固定",
      "stance": "坐",
      "facing": "面向镜头",
      "action": "(开篇) 双手搭桌，自然说话",
      "emotion": "沉稳",
      "visual": "中近景胸像，坐在演播台后，面光，正对镜头",
      "continuity": "开篇",
      "end_frame": "面向镜头，双手搭桌沿，嘴自然闭合",
      "prompt": "视频组全文，含参考绑定和分时提示词"
    }
  ]
}
```

`shots[].prompt` 必须是可直接送给模型的完整视频组文本。`continuity` 只有 `开篇` 或 `承接上段尾帧`。

## 成片衔接（本 skill 只管规则，不负责抽帧）

- 第 1 段：人物多视图 + 场景多视图 + 音色 + 本段提示词。
- 第 2 段起：再挂上一段精确尾帧逐像素提取的同尺寸结构线稿；提示词要求构图与人物位置比例一一对应，同时明确该图是普通参考图而不是首帧，写实外观不得取自图3。
- 各段视频分辨率、帧率、画幅必须一致，才能无损拼接。
- 不要在两段之间写转场、叠化、闪白。口播靠动作连续，不靠转场。

## 交稿前检查

- 口播稿每个字都出现在某一段 `台词` 里，顺序不变，无漏句、无加句、无改写。
- 每段时长在当前模型时限内，且 ≥ 最短时长。
- 全片姿态一致；第 1 段之外都标注了承接尾帧，且每段都有 `尾帧`。
- 每段提示词都绑定了人物板、场景板、音色；第 2 段起还有上一段精确尾帧逐像素提取的结构线稿。
- 没有第二人、换装、换景、走动、字幕、配乐。
- JSON 与分镜表、视频组一致。
```
