# 数字人口播工作台 · 产品需求

> 状态：需求已对齐，可作为技术方案输入  
> 日期：2026-08-14  
> 配套：口播 Skill 见 [`../skills/koubo/SKILL.md`](../skills/koubo/SKILL.md)

## 1. 产品定义

本地 / 内网 Web 工作台：把口播人物、空场景、音色做成可复用资产，再用口播稿 + 资产 + 口播 Skill，经可编辑分镜，调用全能参考视频模型逐段生成，并用上一段尾帧把多段接成一条成片。

一期做完整闭环，不是只做资产库。

```text
资产库（人物 / 场景 / 音色）
        ↓ 选用
口播稿 + Skill + 视频模型
        ↓
可编辑分镜（按模型单段时限切组）
        ↓
逐段生成（第 1 段多参考；第 2 段起 + 上一段尾帧）
        ↓
按段重试 → 拼接成片
```

## 2. 目标与非目标

### 2.1 一期要达成

- 三类资产可入库、可复用、可在制作时选用。
- 人物可「上传成品多视图」或「多角度原图生成一张人物多视图」。
- 场景可上传、文生图、图生图，核心交付物是一张场景多视图。
- 音色可浏览器录音或本地上传（≤15 秒），可绑定到人物。
- 制作页：大口播稿 + 人物 / 场景 / 音色 / 视频模型 / Skill。
- 按口播 Skill 出可编辑分镜，用户改完再出片。
- 视频模型一期：Seedance 2.0、Seedance 2.5；架构按「全能参考」预留扩展。
- 图片模型一期：gpt-image-2；同样可换。
- 多段视频用尾帧衔接后拼接成片；失败按段重试，不整片推倒。

### 2.2 一期不做

- 完整多租户 SaaS、账号体系、云端对象存储。
- 独立整篇 TTS，再拿成片音轨去驱动口型。
- 界面上「选择首帧图」；也不先合成一张「人在场景中」的起始图。
- 纯文生人物（不上传照片只写描述）。
- 1080p / 4K 出片。
- 除口播以外的其他 Skill（动态换景、带货分镜、短剧等可预留接口）。
- 字幕、花字、Logo、BGM、片头片尾包装。

## 3. 使用对象与形态

| 项 | 结论 |
|---|---|
| 使用者 | 单用户或小团队内部制作 |
| 形态 | 本地 / 内网 Web 工作台 |
| 存储 | 资产、分镜、分段视频、成片落本机或局域磁盘 |
| 模型 | 调外部 API，视频 / 图片均可切换 provider |

## 4. 信息架构

两块主功能，外加一次制作任务的存档。

```text
工作台
├── 资产库
│   ├── 人物
│   ├── 场景
│   └── 音色
├── 口播制作
│   ├── 写稿与选资产
│   ├── 分镜（可编辑）
│   └── 生成与成片
└── 制作任务（一次成片的存档）
```

资产全局复用，不跟某一次成片绑死。制作任务只引用资产 ID，并保存当次所用的稿、分镜和产出文件。

## 5. 资产库

三类资产结构统一：每条有 **名称、简介、核心交付物**。

### 5.1 人物

两条入库路径：

| 路径 | 用户做什么 | 系统做什么 |
|---|---|---|
| 上传成品 | 上传已有人物多视图 | 校验后入库 |
| 多图制作 | 上传多张角度图（建议：正脸、侧面、背面、微微张嘴） | 用图片模型生成 **一张人物多视图** 再入库 |

入库字段：名称、简介、来源图片、最终人物多视图、可选默认音色。

**核心交付物：一张人物多视图。**  
板上固定四格：**正脸大图、正面、侧面、微张嘴**。背面只作制作时的参考输入，不进最终板。

一期不支持纯文生人物。

### 5.2 场景

画面里不能有人。来源：上传 / 文生图 / 图生图。

**核心交付物：一张场景多视图。**  
四格固定：**正面主机位、斜侧 45°、远景建立、讲台/桌面特写**。

用于后续多参考，不是单张空镜。

### 5.3 音色

- 浏览器在线录入，或本地音频上传。
- 不超过 15 秒。
- 可绑定到某个人物，作为该人物的默认音色；制作时仍可改选。
- 一期不做独立 TTS 整篇合成。这段音频只作为视频模型的 **音色参考**；口播内容由模型按该段文案自己出声。

## 6. 内置 Skill

一期只内置 **口播 Skill**，制作时默认选中。完整规则以 [`skills/koubo/SKILL.md`](../skills/koubo/SKILL.md) 为准。

Skill 是可执行约束，不是页面装饰。它至少决定：

- 怎么按所选模型单段上限切分镜（Seedance 2.0 = 15 秒，2.5 = 30 秒）。
- 提示词怎么写（说话、看镜头、口型、手势、机位）。
- 镜头和动作幅度：口播 Skill 默认 **固定机位**（坐或站，人不乱跑）。后续 Skill 再放开走动、换景、调度。
- 多段怎么接：第 2 段起必须吃上一段尾帧。
- 禁止项：画面里出字幕 / Logo / 小字、无故换装换脸、凭空加人、配乐。

工作台生成分镜时读取该 Skill；用户改分镜字段后，按同一 Skill 重生成对应视频组提示词。

## 7. 口播视频制作

### 7.1 界面

- 大输入框：口播稿。
- 底下一排：选择人物、选择场景、选择音色、选择视频模型、选择 Skill（默认口播）。
- **不提供「选择首帧图」。**

制作参数：

| 参数 | 选项 | 默认 |
|---|---|---|
| 画幅 | 16:9 / 9:16 | 16:9 |
| 分辨率 | 480p / 720p | 720p |
| 视频模型 | Seedance 2.0 / Seedance 2.5（后续可加其他全能参考模型） | 由实现指定，需可切换 |
| Skill | 一期仅口播 | 口播 |

人物若已绑定默认音色，选中人物后音色可自动带出，允许改选。

### 7.2 工作流

```text
口播稿 + 人物多视图 + 场景多视图 + 音色样本 + 口播 Skill + 所选模型
  → 生成可编辑分镜表（及对应视频组提示词）
  → 用户改台词 / 时长 / 运镜 / 画面 / 提示词
  → 确认后逐段生成
       第 1 段：人物板 + 场景板 + 音色 + 该段提示词/台词 → 视频模型
       第 2 段起：上一段尾帧 + 人物板 + 场景板 + 音色 + 提示词
  → 失败则只重试该段
  → 全部分段通过后拼接成片
```

第 1 段不先合成「人在场景中」的首帧图，把人物板、场景板当多参考直接交给模型。

### 7.3 分镜必须可编辑

提交口播稿后不能黑盒直出视频。先出分镜，用户改完再生成。

分镜列（与口播 Skill 一致）：

| 序号 | 台词 | 时长 | 景别 | 运镜 | 姿态 | 朝向 | 动作 | 情绪 | 画面 | 承接 | 尾帧 |

工作台以 JSON 为源，分镜表和视频组由同一份数据渲染。字段定义见口播 Skill。

### 7.4 生成与失败

- 一组视频组 = 一次模型调用。
- 按段排队生成，后一段依赖前一段尾帧，不能把整条时间线无依赖地并行出完。
- 某段失败：保留已成功段，只重试 / 重生成失败段（可用改过的提示词）。
- 不要因为一段失败就把整片任务作废。
- 各段分辨率、帧率、画幅必须一致，才能无损拼接。
- 段与段之间不写转场、叠化、闪白。

### 7.5 制作任务存档

一次制作另存为一条任务，至少包括：

- 口播稿
- 当次选用的人物 / 场景 / 音色（引用 + 名称快照）
- 视频模型、Skill、画幅、分辨率
- 分镜 JSON 与各段提示词
- 各段视频文件、对应尾帧图
- 拼接后的成片

任务可回看、可对某段再生成、可重新拼接。

## 9. 模型与扩展

| 能力 | 一期 | 扩展原则 |
|---|---|---|
| 图片 | gpt-image-2 | 可切换其他图片模型；人物/场景多视图生成走同一图片接口 |
| 视频 | Seedance 2.0、Seedance 2.5 | 只扩展「全能参考」模型（图 + 视频 + 音频 + 文本） |
| 声音 | 不单独接 TTS | 音色文件作为视频模型音频参考 |

Seedance 单段能力（产品按此切分镜）：

| 模型 | 单段最长 | 音频参考 |
|---|---:|---|
| Seedance 2.0 | 15 秒 | 适合一期音色 ≤15 秒的设定 |
| Seedance 2.5 | 30 秒 | 仍用同一条 ≤15 秒音色作参考 |

## 10. 口播画面约束（口播 Skill 摘要）

完整条款以 Skill 正文为准，产品层需要保证界面和生成管线不与之冲突：

- 全片姿态只允许坐或站，中途不变。演播室 / 会议室默认坐，讲台默认站。
- 默认中近景胸像、面向镜头、固定机位；一段里最多一次极轻推近。
- 禁止走动、换景、第二人、换装换脸、画面内字幕与配乐。
- 台词必须原文切段、原文进提示词，模型按音色参考逐字说，不得改写。
- 宁可接近模型上限做连续长段，也不要切成一堆短镜头。

后续若新增「动态口播」Skill，用另一份约束放开走动和调度，不改本期口播 Skill 的默认行为。

## 11. 已知风险（不改主路径，写入设计约束）

1. **模型自带声**：Seedance 可能改写部分台词，段与段之间语速、情绪会跳。分镜必须锁定「逐字说这段原文」；成片后应能回听对词。
2. **第 1 段不合成首帧**：人站哪、与讲台的空间关系更不可控。提示词必须写死机位、景别、人物位置。
3. **通用视频模型**：即使有尾帧衔接，五官、服装、场景仍可能漂。每一段都要继续挂人物板和场景板，不能只传尾帧。
4. **真人口播**：Seedance 对真人上传有过限制。人物若来自真实照片，上线前要用目标账号测审核策略。

## 12. 一期验收

1. 能入库至少 1 个人物（含多图制作出多视图）、1 个场景多视图、1 条音色。
2. 人物、场景、音色可在多次制作任务中复用。
3. 提交一篇超过单段时限的口播稿后，得到可编辑分镜；改词、改时长后提示词同步更新。
4. 用 Seedance 2.0 或 2.5 逐段生成，第 2 段起使用上一段尾帧。
5. 某段失败后可单独重试，已成功段保留。
6. 全部分段成功后拼出一条 16:9 或 9:16、480p 或 720p 的成片，并写入制作任务。
