## Bug 修复：真人模型分镜不显示

问题：选择 Seedance 2.0（真人）模型生成分镜后，页面显示「分镜就绪」，但分镜表格空白。

根因：`apps/api/src/schemas/storyboard.ts` 中 `StoryboardSchema.model` 枚举未包含 `seedance-2.0-real` / `seedance-2.5-real`。生成时分镜写入文件时模型被强制覆盖为真人模型，但后续 `readStoryboard()` 解析该 JSON 时 schema 校验失败，返回 `null`，导致 API 返回 `storyboard: null`，前端无数据可渲染。

修复：
- `StoryboardSchema.model` 枚举新增 `seedance-2.0-real`、`seedance-2.5-real`
- `MODEL_LIMITS` 同步补充这两个模型的时长限制
- `services/generation.ts` 中的模型类型断言一并扩展，避免后续类型错误

## Bug 修复：真人模型 "may contain real person" 风控报错

问题：已配置 ARK_ASSET_AK/SK/GROUP_ID，真人模型生成仍报 `input image 'content[1]' may contain real person`。

根因链：
1. 原 `volcengineAsset.ts` 的 `uploadFileToArk()` 调用 `${arkBaseUrl}/contents/uploads`，该端点不存在 → 404
2. 素材库流程第一步即失败，静默回退 base64 data URL 直接发给方舟
3. 方舟真人模型对 base64 人脸图触发风控 → "may contain real person"
4. 另发现 `CreateAsset` 只接受公网 HTTP(S) URL，data URL / base64 被拒 `InvalidParameter.URL`

修复：
- 移除 `uploadFileToArk()`；新增 `resolvePublicUrl()`：本地路径 → `ARK_ASSET_PUBLIC_BASE_URL/files/<kind>/<id>/<rel>`（服务已有 `/files` 静态路由）
- 新增 `hasPublicBaseUrl()`；真人模型任一参考图未过素材库 → **直接抛错**（不再回退 base64），错误提示配置 ARK_ASSET_PUBLIC_BASE_URL
- 修复普通模型分支 base64 双重编码 bug（原 `dataUrl(dataUrl(p))` 把本地路径当 base64 再编码导致读文件失败）
- 所有外部请求（CreateAsset/GetAsset/提交/轮询/下载/取消）加耗时+状态+Code/Message 日志；图片 base64 不入日志；AK 用 `redactAk()` 脱敏
- 修复 `videoArk.ts` 中 `imageUrls` 类型声明缺 `reason` 字段导致的 typecheck 错误
- 同步 golden 快照（koubo 模板「其他需求」已加严措辞：表情自然有神采/画面内不得出现任何叠加文字），测试 6/6 通过
- 清理 scripts/diag-asset*.mts 临时诊断脚本

## OSS + 人物资产库火山审核集成（对标 Toonflow）

参考 `/Users/naodoo/data/duanju/Toonflow-app`（src/utils/oss.ts + src/utils/volcengineAsset.ts），实现人物图片完整审核链路：OSS 上传取公网 URL → CreateAsset 提交审核 → 轮询 GetAsset → assetId 落库 → 真人模型生成时自动复用。

### 新增
- `apps/api/src/providers/oss.ts`：阿里云 OSS（ali-oss SDK，已装依赖）。`uploadImageToOss(absPath)` 用内容 sha256 做 key 去重（head 探测），返回 `OSS_PUBLIC_BASE_URL/<key>` 公网 URL
- db.ts：characters 表新增 `volc_asset_id/status/reason/group_id/submitted_at/checked_at`（ensureColumn 兼容旧库）
- 路由：`POST /api/characters/:id/volc-asset`（提交审核）、`GET /api/characters/:id/volc-asset`（GetAsset 刷新）；serialize 输出 volc_asset
- `volcengineAsset.ts`：`resolveAssetSourceUrl()` 公网 URL 优先级 = http URL → OSS 上传；新增 `submitCharacterAsset` / `refreshCharacterAsset` / `getApprovedCharacterAsset`
- 前端 AssetsView 人物卡片：「提交火山审核」「查询审核」按钮 + 火山状态徽标（已过审/审核中/被驳回）

### 生成流程
- `VideoGenRequest.characterId`（generation.ts 传入 job.character_id）
- videoArk 真人模型：images[0]（人物板）优先查 characters 表 approved assetId 直接 `asset://`；场景板/尾帧走 `prepareRealReferenceList`（OSS 优先提交素材库）

### 待用户配置（OSS）
`.env`：`OSS_ACCESS_KEY_ID/SECRET/REGION/BUCKET/PUBLIC_BASE_URL`（bucket 需公读或 CDN）。配置后无需公网暴露本服务。
