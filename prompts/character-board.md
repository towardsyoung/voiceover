# 人物多视图表提示词

产品交付物固定为一张 2×2 板：**正脸大图、正面、侧面、微张嘴**。  
布局与格子与短剧 `identityBoard` / `threeView` 不同，不要照搬 16:9 身份板或 4:1 三视图。

## 系统模板

先拼 `prompts/style-prefix.md`，再拼下面正文，最后追加用户简介。

```text
根据参考图制作一张人物设定多视图表。单张图片，2×2 四格，干净浅灰影棚背景，柔和侧顶光，摄影棚无缝背景纸。
各格同一人、同一发型、同一服装、同一体态、同一肤色与配饰，禁止换脸换装。

# 布局（最高优先级）
左上 图1 正脸大图：胸像以上，面部占该格 60–70%，完全正对镜头，双肩水平，眼神直视，中性闭口，下巴微收，不裁头顶与下巴。
右上 图2 正面：半身或过腰，同一人同一装，自然站/坐姿，双手可见且不挡脸。
左下 图3 侧面：约 90° 侧向镜头，头可微转向镜头，同一发型与服装轮廓。
右下 图4 微张嘴：正面胸像，嘴唇自然微启，可见上齿，表情中性，不是大笑或说话中的夸张口型。

# 正脸姿态（图1、图2、图4）
完全正对镜头；头部端正不歪不仰不低；中性无表情（不必微笑）；半身聚焦面部识别度，不要时尚大片构图。

# 身份锁定
所有格子：相同面部比例、相同发型、相同服装、相同身体比例、相同鞋履与配饰。
背面参考图只用来锁定发型和服装背面结构，不要单独输出背面格。

# 参考图约定
第 1 张=正脸，第 2 张=侧面，第 3 张=背面，第 4 张=微张嘴。缺某张则忽略对应句，至少保留一张正脸类参考。

# 负面（必须规避）
侧脸当正脸，半侧脸，歪头，仰头，低头，戏剧化表情，性感姿势，浓妆，强侧光/伦勃朗光，
文字、箭头、色卡、水印、第二人、换装、美颜到换脸、漫画风、3D 渲染感、
背面格、五视图、九宫格、重复同一格、裁切头顶或下巴、畸形手指。

人物名称：{name}
人物简介：{bio}
```

画幅：`1536×1024`（约 3:2 横板）。一期不做纯文生人物。

## 从短剧刻意不抄的部分

| 短剧 | 口播 |
|---|---|
| 左 1/3 半身 + 右三全身（正/侧/背） | 2×2：正脸大图 / 正面 / 侧面 / 微张嘴 |
| 16:9 身份板或 4:1 三视图 | 3:2 四格板 |
| 背面作为成格 | 背面只作输入参考 |
| 武器特写、手写标签、角色 ID 文字块 | 禁止任何字 |
