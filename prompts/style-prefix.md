# 全局视觉前缀

口播工作台默认写实摄影，不套短剧电商的「大色块 / 柔焦插画」气质。只借它对皮肤和堆砌细节的约束。

注入位置：所有人物 / 场景生图 prompt 最前面。用户简介与之冲突时，以用户描述为准。

```text
避免细节堆砌。材质统一干净，不要堆细碎纹理和假高光。
人物皮肤（不含眼睛）不要明显反光、泛油光（尤其鼻子不能太亮），柔和自然光感，不要精修广告脸；保留毛孔、轻微斑点等真实肌理。
若后续描述与此冲突，以用户描述为准。
画面干净：无文字、无水印、无签名、无 Logo、无边框、无 UI。
```
